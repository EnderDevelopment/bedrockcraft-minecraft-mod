# BedrockCraft

BedrockCraft is a custom Minecraft mod designed specifically for Bedrock Edition. This mod enhances the gameplay experience with unique features and customizations tailored to the Bedrock platform.

## Installation

1. Install the Fabric loader for Minecraft 1.20.1.
2. Place the mod jar in the `mods` folder.

## Usage

1. Launch Minecraft Bedrock Edition.
2. Ensure the Fabric loader is properly installed.
3. Start a new world or load an existing one.
4. The mod will initialize and display a custom message in the console.
